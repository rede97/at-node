Config Export / Import

Export downloads all non-secret config keys as one JSON object. Import accepts any JSON object of key: value pairs — keys this firmware does not support are ignored. Secret keys (passwords, tokens) are never exported; add them manually to an import file when needed.

HTTP API

Base: /at-node/cmd/. GET endpoints take query params, POST take form params. All return JSON.
